# 我的媒体库（MyLibrary）

在 MoviePilot 左侧导航栏浏览本地媒体库：NFO 元数据 + 本地图片海报墙。

## 功能

- **海报墙**：纯海报卡片，悬停浮出渐变详情层（年份 / 片名 / 简介）
- **角标**：左上类型（电影蓝 / 剧集靛），右上评分（≥8 绿 / ≥6.5 琥珀 / 更低橙）
- **搜索筛选**：按片名 / 年份 / 导演搜索，按类型与清晰度筛选，按片名 / 年份 / 评分 / 体积排序
- **双视图**：海报墙与列表视图切换，选择会记住
- **详情弹窗**：横版背景图 + 竖版海报 + 时长类型标签 + 演职员名单 + 外链 + 文件清单
- **豆瓣 ID 自动补齐**：新片入库后后台自动查询豆瓣 ID 写入缓存，详情页豆瓣链接随之生效

## 配置

| 字段 | 说明 |
| --- | --- |
| `enabled` | 是否启用插件 |
| `library_path` | 媒体库根目录，例如 `/media/Videos/电影` |
| `poster_size` | 海报尺寸 `small` / `medium` / `large` |
| `douban_auto` | 是否后台自动补齐豆瓣 ID（默认开） |

## 依赖的数据

插件只读取本地文件，不修改媒体库任何内容；唯一写入的是豆瓣 id 缓存：

- `<影片目录>/*.nfo` — 元数据（片名、年份、简介、类型、评分、演职员、时长等）
- `<影片目录>/poster.jpg` 等 — 竖版海报
- `<影片目录>/landscape.jpg` 等 — 横版背景
- `<媒体库根目录>/.douban_ids.json` — 豆瓣 id 缓存（读；开启自动补齐时由后台线程写入）

自动补齐的节奏：只查缺失条目、每部间隔 1.2 秒、触发豆瓣限流后冷却 30 分钟、
没有待补条目时不发请求（每 5 分钟看一次是否有新片）。也可用
`tools/fetch_douban_ids.py` 手动补，两者缓存格式一致。

所有 NFO 解析使用 Python 标准库 `xml.etree.ElementTree`，不依赖 MoviePilot 内部实现，因此对宿主升级更稳健。

## API

| 路由 | 方法 | 说明 |
| --- | --- | --- |
| `plugin/MyLibrary/library` | GET | 扫描媒体库，返回条目列表与汇总（需登录） |
| `plugin/MyLibrary/poster` | GET | 按相对路径返回本地图片（防目录穿越） |
