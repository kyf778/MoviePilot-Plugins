# 我的媒体库（MyLibrary）

在 MoviePilot 左侧导航栏浏览本地媒体库的海报墙。

## 功能

- 扫描媒体库目录，读取每部影片目录内的 NFO 元数据与本地图片
- 展示海报墙，悬停卡片可看简介，点开看导演、演职员、清晰度、体积、文件清单
- 一键跳转 TheMovieDb / IMDb / 豆瓣
- 豆瓣 ID 后台自动补齐（也可手动跑脚本）：见 [豆瓣 ID 自动补齐](#豆瓣-id-自动补齐)

## 使用

1. 在 MoviePilot 中安装「我的媒体库」插件
2. 进入插件配置，填写媒体库根目录，例如 `/media/Videos/电影`
3. 保存后重启 MoviePilot，侧栏会出现入口

### 目录结构

插件按「一级目录 = 一部影片」扫描：

```text
/media/Videos/电影/
├── 大战争家廓尔凯撒 (2006)/
│   ├── movie.nfo
│   └── poster.jpg
└── 007：大破天幕杀机 (2015)/
    ├── movie.nfo
    └── poster.jpg
```

- NFO 文件名不限（`movie.nfo`、`*.nfo` 均可），取第一个成功解析的
- 图片支持 `poster.jpg` / `folder.jpg` / 目录内首张图片
- 子目录会被当作独立影片扫描；**不要在影片目录里再套一层目录**

## 豆瓣 ID 自动补齐

NFO 里通常没有豆瓣 ID，MoviePilot 的豆瓣接口也拿不到 id，因此插件用一个后台线程走豆瓣
网页搜索自行补齐，结果写入媒体库根目录的 `.douban_ids.json`（格式与手动脚本一致）。

运行规则（都是为了不触怒豆瓣的反爬）：

| 行为 | 说明 |
|---|---|
| 只补缺失的 | 缓存里已有 ID 的条目永不重复请求 |
| 请求间隔 | 每部 1.2 秒，串行，不发并发请求 |
| 空转保护 | 没有待补条目时完全不发请求，每 5 分钟看一次是否有新片 |
| 反爬冷却 | 收到「搜索访问太频繁」后暂停 30 分钟 |
| 失败退避 | 同一进程内查不到的条目不反复重试 |
| 写入方式 | 先重读再原子替换，不会写坏缓存或覆盖脚本的写入 |

设置页的「自动补齐豆瓣 ID」开关可关闭该行为。关闭后仍可用脚本手动补：

```bash
python tools/fetch_douban_ids.py /media/Videos/电影
```

参数：

| 参数 | 说明 | 默认值 |
|---|---|---|
| `library` | 媒体库目录（位置参数） | 必填 |
| `-o, --output` | 输出文件路径 | `<library>/.douban_ids.json` |
| `--delay` | 每次请求间隔秒数 | `1.2` |

脚本与插件都通过 `m.douban.com` 逐部搜索，**间隔不要调低**。
生成的 JSON 不会被提交到仓库（已在 `.gitignore` 中）。

## 隐私

插件只读取本地文件，不向外部发送媒体库路径或文件名。
自动补齐与脚本只向豆瓣发送影片标题做搜索，请自行评估使用频率。

## 常见问题

**条目数不对**
确认配置路径指向影片所在的那一层。若影片在 `电影/` 子目录下，路径要写到该子目录。

**海报不显示**
确认影片目录下有 `poster.jpg` 等图片；图片名含特殊字符也能识别，但请避免中文路径编码问题。

**豆瓣链接为空**
该影片尚未补到 ID：可能是刚入库（等几分钟，后台会自动补），也可能是豆瓣搜不到或
匹配度太低（插件宁可不给，也不挂错链接），或正处在限流冷却期。可手动跑
`fetch_douban_ids.py` 核对。
